    Référence de l'API

    Documentation générée automatiquement à partir du code et de ses annotations de type.

    État du jour

    Télécharge (ou lit dans dossier_sources) les fichiers officiels et renvoie les disponibilités enrichies (nom, laboratoire, MITM, code ATC) + un rapport de lecture.

    Modèles

    Une ligne du fichier de disponibilité : une présentation (code CIP13) d'un médicament.

    cle property

    Identifiant stable d'une présentation, utilisé pour comparer deux jours.

    Bases: str, Enum

    Statut de disponibilité, déduit du LIBELLÉ fourni par l'ANSM.

    On ne code pas en dur la correspondance « code -> statut » : si l'ANSM ajoute un nouveau statut, il devient INCONNU au lieu de faire planter l'outil.

    est_indisponible property

    Vrai pour une rupture ou une tension d'approvisionnement.

    Changement détecté pour une présentation entre deux jours.

    disponibilite property

    La version la plus récente connue de la présentation.

    Bases: str, Enum

    Comparaison

    Liste des événements pour passer de avant à apres, triés par type puis par nom.

    Rejoue des événements sur un état (utilisé pour vérifier la cohérence du diff).

    Historique et indicateurs

    photos : liste de (jour, disponibilités). Renvoie les épisodes clos puis en cours.

    duree_jours(reference)

    Durée en jours ; pour un épisode en cours, jusqu'à la date de référence.

    Photos quotidiennes

    Photos quotidiennes de l'état des disponibilités.

    Chaque jour est enregistré dans un CSV nommé AAAA-MM-JJ.csv, trié par clé : dans un dépôt Git, le diff entre deux jours reste ainsi lisible ligne à ligne (technique dite de « git scraping »).

    enregistrer(disponibilites, dossier, jour)

    Enregistre la photo du jour (écrase une photo existante du même jour).

    jour_precedent(dossier, jour)

    Dernière photo strictement antérieure à jour.

    lister_jours(dossier)

    Jours disponibles, du plus ancien au plus récent.

    Téléchargement

    Renvoie le contenu du fichier nom (clé de FICHIERS), à jour si possible.
